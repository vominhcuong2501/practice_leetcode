    🎯 Goal cho Frontend Engineer

Bạn không cần grind hard như competitive programming.

Mục tiêu FE nên là:

- JS fundamentals mạnh
- giải được easy + medium phổ biến
- hiểu patterns
- code clean
- explain được solution

👉 Chỉ cần:

40–60 bài quality
luyện đúng pattern
explain được khi PV

là đủ pass rất nhiều công ty FE mid-level.
